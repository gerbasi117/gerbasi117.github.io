Three completed enhancements to the CS 410 investment-company client-service application: software design, algorithms/data structures and database integration. Final ePortfolio presentation remains in progress.

Enhancement one completed

Software engineering & design

Refactored the application into a modular C++17 structure with focused responsibilities for application flow, authentication, client management and input handling.

Separated responsibilities and improved validation and testability while preserving the original program’s purpose.

Enhancement two completed

Algorithms & data structures

Added stable client IDs and unordered_map storage for average O(1) ID lookup and ID-based updates.

Implemented sorted views using vectors and std::sort, O(n log n) sorting, O(n) service filtering and documented trade-offs.

Enhancement three completed

SQLite database integration

Added persistent users, clients and audit-log tables, prepared statements, constraints and database-backed authentication.

Client updates and audit records are committed together in a transaction, with the in-memory client map updated after the database succeeds.
