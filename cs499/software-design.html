Artifact and Origin

Project2.cpp originated in CS 410: Reverse Software Engineering. The original investment-company program authenticated a user, displayed client records, validated menu input, and changed a selected service.

Enhancement

The program was refactored into Client, InputValidator, AuthenticationService, ClientManager, and AppController components. A ServiceType enum replaced raw service values, main became a small startup function, and CMake provided a repeatable C++17 build.

Skills Demonstrated

Object-oriented programming, encapsulation, separation of responsibilities, modular architecture, validation, error handling, testable design, documentation, and security-aware development.
