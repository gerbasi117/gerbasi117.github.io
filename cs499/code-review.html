Existing Functionality

Original Artifact

The original artifact is a C++ investment-company client-service application created in CS 410: Reverse Software Engineering. It authenticates a user, limits failed login attempts, validates numeric input, displays client records, and allows an authorized user to change a client’s selected service.

Code Analysis

Areas for Improvement

The original application stores all functionality in one source file. Client data, authentication, input validation, menu control, display logic, and update logic are closely connected. Clients are identified by their position in a vector, and all records are recreated from hardcoded values each time the program starts.

Enhancement Plan

Three Enhancement Categories

Software Design and Engineering

Refactor the procedural single-file program into focused classes for client data, input validation, authentication, client management, and application control.

Algorithms and Data Structures

Add stable client IDs, unordered-map lookup, sorting, filtering, and clear analysis of the trade-offs between direct lookup and ordered presentation.

Databases

Add SQLite persistence for users, clients, and audit history using prepared statements, constraints, foreign keys, transactions, and rollback handling.
